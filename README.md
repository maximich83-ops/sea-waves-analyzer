# sea-waves-analyzer

CLI-утиліта мовою Go для аналізу висот морських хвиль.
Генерує набір висот для заданої акваторії, рахує статистику, розподіляє хвилі за категоріями,
знаходить повтори й попереджає про небезпечні хвилі.

> Лабораторна робота № 3 «Безпечна модульна CLI-утиліта», варіант 5 «Морські хвилі».
> Дисципліна «Основи програмування захищених інформаційних систем», ВНТУ.

## Можливості

- підкоманди `analyze`, `help`, `version`;
- статистика: кількість, сума, мінімум, максимум, середнє;
- категорії висот: спокійно, невеликі хвилі, значні, небезпечні;
- пошук повторюваних значень і кількості однакових пар;
- номер першої хвилі, вищої за заданий поріг (`--limit`);
- відтворювана генерація з фіксованим `--seed`;
- перевірка всіх аргументів до виклику генератора, помилки — у stderr, коди завершення 0/1/2.

## Вимоги

- Go (версія вказана в `go.mod`);
- доступ до інтернету під час першого збирання — для завантаження пакета-генератора
  [`waves`](https://github.com/compilyator/VNTU_GoLang) (`github.com/compilyator/VNTU_GoLang/labs/Lab2Data/waves`).

## Встановлення та збирання

```bash
git clone https://github.com/maximich83-ops/sea-waves-analyzer.git
cd sea-waves-analyzer
go mod download
go build -o swa.exe .      # Windows
go build -o swa .          # Linux / macOS
```

Без збирання можна запускати через `go run`:

```bash
go run . -- analyze --count 10 --subject BlackSea
```

> Через `go run` на ненульовий код утиліти сам `go run` виводить `exit status N`
> і повертає власний код 1. Точні коди завершення перевіряйте на зібраному файлі.

## Використання

```text
sea-waves-analyzer <підкоманда> [прапорці]

Підкоманди:
  analyze   згенерувати й проаналізувати висоти хвиль
  help      показати довідку
  version   показати версію
```

### Прапорці `analyze`

| Прапорець | Обов'язковий | Опис |
|-----------|:-----------:|------|
| `--count N` | так | кількість значень, від 5 до 100 |
| `--subject НАЗВА` | так | назва морської акваторії, непорожня, до 100 символів |
| `--seed S` | ні | ціле число для відтворюваної генерації |
| `--limit H` | ні | порогова висота 0–12 м: вивести номер першої хвилі, вищої за поріг |

Значення, що починається з `-`, передавайте через `=`: `--subject=-Північ`.

### Приклад

```bash
./swa analyze --count 10 --subject BlackSea --seed 42 --limit 5
```

Помилковий виклик:

```bash
./swa analyze --count 4 --subject BlackSea
```

```text
помилка: кількість значень поза межами: 4 (дозволено від 5 до 100)
Довідка: sea-waves-analyzer analyze -h
```

### Категорії висот

| Категорія | Діапазон | Правило |
|-----------|----------|---------|
| спокійно | до 0,5 м | h ≤ 0,5 |
| невеликі хвилі | 0,6–2 м | 0,5 < h ≤ 2,0 |
| значні | 2,1–5 м | 2,0 < h ≤ 5,0 |
| небезпечні | понад 5 м | h > 5,0 |

### Потоки й коди завершення

| Код | Значення | Куди виводиться |
|:---:|----------|-----------------|
| 0 | успіх, `help`, `version`, `analyze -h` | stdout |
| 1 | помилка генератора або некоректні дані | stderr |
| 2 | помилка виклику: невідома підкоманда чи прапорець, відсутні або некоректні аргументи | stderr |

Звичайний результат завжди йде в stdout, тому його можна перенаправити у файл
(`./swa analyze ... > report.txt`), а помилки лишаться на екрані.

## Структура проєкту

```text
sea-waves-analyzer/
├── main.go              # CLI: підкоманди, прапорці, виклик генератора, виведення, коди завершення
├── main_test.go         # тести CLI через io.Writer і тестове джерело даних
├── go.mod / go.sum
└── analyzer/            # предметна логіка, не залежить від CLI
    ├── doc.go           # опис пакета
    ├── validate.go      # межі домену, помилки, перевірка count / subject / limit
    ├── category.go      # тип WaveCategory, Classify, CategoryCount, підрахунок категорій
    ├── series.go        # тип WaveSeries: конструктор з інваріантами, FirstAbove, Analyze
    ├── stats.go         # тип Statistics і метод Stats
    ├── repeats.go       # тип Repeat: пошук повторів і пар
    ├── report.go        # тип Report: TotalPairs, HasDangerous
    └── *_test.go        # табличні тести для кожного файлу
```

`main.go` нічого не обчислює: він лише читає аргументи, викликає пакет `analyzer` і друкує результат.
Серію `WaveSeries` можна створити тільки через `NewWaveSeries`, який перевіряє назву, кількість
значень і діапазон 0–12 м та копіює вхідний зріз.

## Тести

```bash
go test ./...          # усі тести
go test ./... -v       # з переліком підтестів
go test ./analyzer -run TestAnalyze -v   # окремий тест
```

- тести пакета `analyzer` — табличні, на статичних наборах з вручну порахованими очікуваннями;
  покривають межі категорій, повтори, помилки конструктора й межі аргументів;
- тести CLI викликають `run` з `bytes.Buffer` замість stdout/stderr і тестовою реалізацією
  джерела даних, тому не залежать від випадкової генерації.
